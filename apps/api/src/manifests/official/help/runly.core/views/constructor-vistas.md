Ademas de la tabla, el formulario y el detalle que se generan para cada entidad, en la pestana **Vistas** puedes agregar otras formas de ver la informacion con **Nueva vista**:

| Vista | Que muestra | Necesita |
|---|---|---|
| **Dashboard** | Indicadores y graficas (barras, linea, pastel, dona) de una o varias entidades, con conteos, sumas, promedios, minimos y maximos. | - |
| **Kanban** | Tarjetas en columnas por estado; se mueven arrastrando. | Un campo de Seleccion o Si/No para las columnas. |
| **Tarjetas** | Galeria de registros con imagen, titulo, subtitulo y etiqueta. | Para la imagen, un campo de Archivo de tipo Imagen. |
| **Calendario** | Registros en un calendario mensual segun una fecha. | Un campo de Fecha o Fecha y hora. |
| **Linea de tiempo** | Registros ordenados por fecha en una linea vertical, agrupados por dia. | Un campo de fecha (o la fecha de creacion). |
| **Reporte** | Registros agrupados por un campo, con hasta 6 medidas (conteo, suma, promedio...) y totales. | Un campo para agrupar. |

- Al hacer clic en un registro de estas vistas se abre su detalle.
- Cada vista puede aparecer en el menu del modulo desde la pestana **Navegacion**.
- Las vistas respetan los permisos de ver de la entidad y solo muestran datos de la empresa activa.
