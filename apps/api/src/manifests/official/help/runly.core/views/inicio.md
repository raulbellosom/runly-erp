Este es tu inicio en Runly ERP.

- Usa el **menu lateral** para entrar a cada modulo instalado.
- El icono de **ayuda** (arriba a la derecha) siempre muestra la ayuda de la pantalla en la que estas, y te deja preguntar algo en tus propias palabras.
- **Ctrl+K** busca en todo el sistema, incluida la ayuda.
- **Modulos** (dentro de Runly Core, menu lateral) es donde instalas, habilitas o deshabilitas modulos.
- **Configuracion** es donde ajustas los datos generales de tu instancia.
