viewKey: /templates
title: Plantillas
summary: Disenos de pagina reutilizables para no empezar de cero cada vez.
---
Guarda un diseno de pagina como plantilla para reutilizarlo despues en otras paginas.

- Util cuando varias paginas comparten la misma estructura (por ejemplo, paginas de producto o de servicio), para no armarlas desde cero cada vez.
- Al crear una pagina nueva desde una plantilla, puedes editar libremente el contenido sin afectar la plantilla original.
- Actualizar una plantilla no cambia automaticamente las paginas que ya se crearon a partir de ella.
