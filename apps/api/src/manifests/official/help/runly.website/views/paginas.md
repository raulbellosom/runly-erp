title: Paginas
summary: Crea y edita las paginas de tu sitio web arrastrando bloques de contenido.
---
Cada pagina se arma arrastrando bloques (texto, imagenes, botones, etc.). Puedes guardarla como borrador o publicarla para que sea visible en tu sitio.

- Arrastra bloques desde el panel lateral y acomodalos en el orden que quieras, sin necesidad de escribir codigo.
- Guarda como borrador para seguir editando sin que los visitantes lo vean; publica cuando este lista.
- Puedes partir de una plantilla existente en vez de armar la pagina desde cero.
- Cada pagina tiene su propia direccion (URL) dentro de tu sitio, que puedes ajustar en sus ajustes.
