title: Blog
summary: Escribe y publica entradas de blog en tu sitio.
---
Crea entradas de blog con el mismo editor de bloques que las paginas, y publicalas cuando esten listas.

- Cada entrada puede tener su propia imagen destacada, fecha de publicacion y estado (borrador o publicada).
- Al usar el mismo editor de bloques que las paginas, no necesitas aprender una herramienta distinta para escribir en el blog.
- Util para contenido que se organiza cronologicamente (noticias, articulos), a diferencia de las paginas fijas de tu sitio.
