title: Formularios
summary: Formularios de contacto que capturan visitantes de tu sitio.
---
Crea formularios (contacto, cotizacion, etc.) para colocarlos en tu sitio; las respuestas quedan registradas y, si tienes el modulo de Growth, se convierten en oportunidades de venta.

- Define los campos que necesitas capturar (nombre, correo, telefono, mensaje, etc.) sin escribir codigo.
- Coloca el formulario en cualquier pagina como un bloque mas del editor visual.
- Cada respuesta llega tambien a Growth (si esta instalado) como un lead nuevo, listo para darle seguimiento.
