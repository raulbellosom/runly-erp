Ajustes generales de tu sitio web, como el dominio y las opciones de posicionamiento en buscadores (SEO).

- Configura el dominio en el que se publica tu sitio, si es distinto al que trae Runly por defecto.
- Los ajustes de SEO (titulo, descripcion) ayudan a que tu sitio se muestre mejor en buscadores como Google.
- Estos ajustes aplican a todo el sitio; los ajustes especificos de una pagina (como su propio titulo) se editan desde esa pagina.
