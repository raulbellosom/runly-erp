El resumen te muestra de un vistazo el estado de tu compania: datos de perfil, direccion registrada y marca visual configurada, con accesos rapidos para editar cada seccion.

- Una barra de progreso al final indica que secciones ya completaste (datos legales, direccion, logotipo) y cuales te faltan.
- Es el primer lugar a revisar cuando das de alta una compania nueva, para saber que falta antes de empezar a operar.
