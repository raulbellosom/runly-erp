viewKey: /chat/external
title: Bandeja externa
summary: Mensajes de visitantes del sitio web publico, atendidos por el equipo de soporte.
---
Esta bandeja concentra los mensajes que llegan desde el widget de chat del sitio web publico (visitantes que aun no son usuarios del sistema).

- Solo la ve el equipo con permiso de gestionar soporte externo — no aparece para el resto de los usuarios.
- Cada conversacion muestra de que pagina/sitio viene el visitante, para dar contexto antes de responder.
- Puedes responder desde aqui igual que en una conversacion normal, incluyendo adjuntos si el visitante los necesita.
- Las plantillas de respuesta rapida (pestana "Plantillas") tambien estan disponibles aqui para agilizar la atencion en preguntas frecuentes.
- Una conversacion resuelta se puede marcar como cerrada para sacarla de tu bandeja de pendientes.
