title: Grupos
summary: Agrupa varias cuentas relacionadas para verlas juntas.
---
Un grupo junta varias cuentas (por ejemplo, todas las de una sucursal o un proyecto) para consultarlas y darles seguimiento en conjunto.

- Util cuando manejas varias cuentas que en la practica funcionan como una sola unidad de negocio (por ejemplo, todas las cuentas de una sucursal).
- Dar acceso a un grupo completo es mas rapido que dar acceso cuenta por cuenta cuando alguien necesita ver todas las de un mismo grupo.
