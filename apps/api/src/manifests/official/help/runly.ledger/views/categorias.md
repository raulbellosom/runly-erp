title: Categorias
summary: Clasifica tus movimientos para saber en que se va o de donde viene el dinero.
---
Crea categorias (por ejemplo "Renta", "Nomina", "Ventas") para asignarlas a cada movimiento y despues poder ver reportes agrupados.

- Una categoria bien pensada es lo que despues te deja responder "¿en que se fue el dinero este mes?" de un vistazo.
- Puedes desactivar una categoria que ya no uses sin afectar los movimientos que ya la tienen asignada.
