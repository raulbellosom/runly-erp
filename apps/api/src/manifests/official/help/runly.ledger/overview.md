title: Libro de cuentas

Runly Libro de cuentas es un registro bancario simple: llevas tus cuentas (bancos, efectivo, tarjetas) y capturas cada deposito o retiro, con el saldo corriente calculandose solo.

- **Cuentas**: cada cuenta bancaria o de efectivo que quieras controlar.
- **Grupos**: agrupa cuentas relacionadas (por ejemplo, todas las de una sucursal).
- **Categorias** y **Tipos**: clasifican cada movimiento para que puedas ver en que se va el dinero.
- **Mis membresias**: a que cuentas tienes acceso y con que rol.

### Alcances y limites

- Puedes exportar e importar movimientos (por ejemplo desde un estado de cuenta).
- No reemplaza un sistema contable formal (pólizas, impuestos) — es un registro operativo de entradas y salidas.
