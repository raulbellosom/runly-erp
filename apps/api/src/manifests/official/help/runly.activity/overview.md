Runly Actividad muestra un historial legible de eventos importantes de toda la empresa: quien hizo que y cuando, en cualquier modulo.

### Alcances y limites

- Es un resumen legible pensado para consultar rapido; para el detalle tecnico de auditoria completo, cada modulo tiene su propia bitacora.
