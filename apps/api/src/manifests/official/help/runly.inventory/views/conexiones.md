title: Conexiones
summary: Activa y configura los modulos que agregan campos o registros a la ficha de cada articulo.
---
Algunos modulos propios de tu empresa pueden **conectarse** a Inventario para agregar informacion a cada articulo; por ejemplo, un modulo de Calibraciones que agrega el certificado y la fecha de calibracion.

- Cada modulo conectado aparece como una tarjeta con su tipo: **Campos** (datos extra del articulo) o **Registros relacionados** (una lista, por ejemplo prestamos o mantenimientos).
- Una conexion nueva llega **pendiente**: revisa sus campos y activala. Al activarla se toman en cuenta los registros que ya existian.
- Por cada campo decide donde se usa: **Formulario** (se edita al editar el articulo y se guarda con el mismo boton), **Detalle**, **Columna** de la lista y **Busqueda**. Solo puedes elegir entre los campos que el modulo ofrece.
- Puedes desactivar una conexion en cualquier momento; los datos no se pierden y vuelven a mostrarse al activarla.
- Si un modulo conectado se desinstala, su conexion queda desactivada; si se reinstala, vuelve a activarse.
- Para ver esta pantalla necesitas el permiso **Gestionar conexiones de inventario**. Si no aparece despues de una actualizacion, un administrador debe usar **Sincronizar modulos** una vez.
