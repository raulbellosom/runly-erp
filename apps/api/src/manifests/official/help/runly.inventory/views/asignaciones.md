viewKey: /inventory/assignments
title: Asignaciones
summary: A que colaborador o area se le asigno cada activo.
---
Consulta y gestiona a quien se le asigno cada activo, y el historial de asignaciones anteriores.

- Asigna un activo a un colaborador o a un area/departamento, segun como organices el control de tu equipo.
- Reasignar un activo (por ejemplo, cuando alguien cambia de puesto) cierra la asignacion anterior y abre una nueva, sin perder el historial de quien lo tuvo antes.
- Util para saber de inmediato quien es responsable de un activo si necesita mantenimiento o si se reporta perdido.
