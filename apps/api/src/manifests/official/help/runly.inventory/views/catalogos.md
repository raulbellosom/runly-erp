title: Catalogos
summary: Categorias, marcas, tipos y modelos reutilizables para clasificar tus activos.
---
Administra los catalogos (categorias, marcas, ubicaciones, tipos y modelos) que despues eliges al registrar un activo, para mantener el inventario organizado.

- Crear categorias claras (por ejemplo, "Equipo de computo", "Mobiliario", "Herramientas") facilita filtrar y generar reportes por tipo de activo.
- Un modelo siempre tiene tipo, marca y nombre, y opcionalmente año (por ejemplo, "XPS 15 · Dell · 2023 · Hardware"). Al crear un modelo puedes crear ahi mismo el tipo o la marca si todavia no existen.
- Un mismo nombre con la misma marca pero distinto año se guarda como un modelo distinto.
- Estos catalogos son los que ve la IA de Registro con IA para sugerir la categoria correcta al identificar una foto.
