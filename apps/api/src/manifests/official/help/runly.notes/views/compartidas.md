Notas de otros usuarios en las que te dieron acceso para ver o editar.

- Segun el permiso que te hayan dado, puedes solo consultarlas o tambien editarlas junto con quien las comparte.
- Si alguien edita una nota compartida mientras tu tambien la tienes abierta, ves sus cambios en tiempo real.
