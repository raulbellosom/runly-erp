viewKey: /notes/trash
title: Papelera
summary: Notas eliminadas recientemente; puedes restaurarlas antes de que se borren definitivamente.
---
Las notas que borraste aparecen aqui temporalmente. Puedes restaurarlas o vaciarlas de forma permanente.

- Restaurar una nota la regresa exactamente a donde estaba (misma carpeta y etiquetas) antes de borrarla.
- Vaciar la papelera es la unica forma de borrar una nota de manera permanente e irreversible.
