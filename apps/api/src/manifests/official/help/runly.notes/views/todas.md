title: Todas las notas
summary: Todas tus notas, organizadas por carpeta y etiqueta.
---
Aqui ves todas tus notas. Crea una nueva, organizala en una carpeta y agregale etiquetas para encontrarla despues facilmente.

- Busca por titulo o contenido para encontrar una nota especifica entre todas las que tienes.
- Una nota puede estar en una sola carpeta a la vez, pero puedes agregarle varias etiquetas si aplica a mas de un tema.
- Crea carpetas nuevas conforme las necesites, sin limite de cuantas puedes tener.
