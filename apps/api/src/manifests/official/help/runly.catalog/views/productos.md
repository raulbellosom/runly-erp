title: Productos

---
Aqui administras el catalogo completo de productos: nombre, precio, codigo, variantes (si aplica) y si esta publicado o no.

- Busca y filtra por categoria o estado de publicacion para encontrar un producto especifico entre muchos.
- Un producto variable (por ejemplo, con talla y color) se configura una sola vez y genera todas las combinaciones automaticamente, cada una con su propio precio y existencia si lo necesitas.
- El detalle de cada producto es donde defines a que categorias pertenece y si ya esta listo para venderse.
- Publicar o despublicar un producto controla si aparece disponible en POS y en el sitio web, sin necesidad de borrarlo.
