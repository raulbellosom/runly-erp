title: Inventario
summary: Cuanto tienes disponible de cada producto.
---
Consulta el stock disponible de cada producto que rastrea inventario.

- Ves de un vistazo que productos estan por agotarse, para reabastecerlos a tiempo.
- Cada variante de un producto (por ejemplo, talla chica vs. grande) lleva su propio conteo por separado.
- Si tu instancia tiene instalado el modulo de Inventario, ahi encontraras el detalle de cada movimiento (entradas, salidas, ajustes); aqui solo ves el disponible actual.
