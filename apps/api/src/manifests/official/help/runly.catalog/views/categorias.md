title: Categorias
summary: Organiza tus productos en categorias para encontrarlos mas facil.
---
Crea y organiza las categorias que despues asignas a cada producto.

- Una categoria bien organizada facilita que los clientes encuentren productos en el sitio web y que tu equipo los ubique rapido en POS.
- Puedes anidar categorias (una categoria dentro de otra) si tu catalogo necesita mas de un nivel de organizacion.
- Un producto puede pertenecer a mas de una categoria a la vez si aplica.
