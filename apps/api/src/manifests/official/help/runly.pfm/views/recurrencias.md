viewKey: /app/m/runly.pfm/recurring
title: Recurrencias
summary: Cargos o ingresos que se repiten cada mes.
---
Registra pagos o ingresos que se repiten (renta, suscripciones, nomina) para que se te recuerden y no se te olviden.

- Define la frecuencia (mensual, quincenal, etc.) y la cartera a la que afecta; Runly te avisa cuando se acerca la fecha.
- Util para anticipar tus proximos cargos sin tener que recordarlos de memoria — el Resumen los muestra como "proximos cargos".
- Si una recurrencia cambia de monto (por ejemplo, una suscripcion que subio de precio), solo actualizas el monto y sigue aplicando hacia adelante.
