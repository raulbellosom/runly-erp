title: Tickets
summary: Sube la foto de un recibo y se registra el gasto automaticamente (con IA).
---
Sube o toma una foto de un ticket de compra; si tu instancia tiene IA configurada, el gasto se registra solo con los datos leidos del recibo. Sin IA, puedes registrar el gasto a mano desde Carteras.
