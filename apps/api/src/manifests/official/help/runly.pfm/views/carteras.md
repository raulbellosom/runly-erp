title: Carteras
summary: Tus cuentas personales (banco, efectivo, tarjeta) y sus movimientos.
---
Cada cartera es una cuenta tuya (por ejemplo "Banco X debito" o "Efectivo"). Aqui registras tus gastos e ingresos y ves el saldo de cada una.

- Ten tantas carteras como cuentas reales manejes (debito, credito, efectivo) para que el saldo de cada una en Runly coincida con la realidad.
- Cada movimiento lleva categoria, monto y fecha; con el tiempo eso es lo que te permite ver patrones de gasto por categoria.
- Si compartes una cartera con alguien mas (por ejemplo, pareja o familia), ambos pueden registrar movimientos sobre la misma cartera.
