title: Aprobaciones
summary: Bandeja de solicitudes, órdenes y facturas que esperan una autorización.
---
Aquí ves lo que espera una decisión.

- Cada aprobación indica el documento, su monto y el motivo (por ejemplo, la política "montos mayores a 50,000 requieren aprobación").
- Aprueba o rechaza con un comentario opcional; la decisión queda registrada con fecha y responsable.
- Solo quien tiene el permiso para decidir aprobaciones de compra puede aprobar o rechazar.
- Esta pantalla solo aparece si tu empresa tiene activada la etapa de aprobaciones.
