El resumen es la pantalla inicial de Compras.

- La franja superior muestra el flujo de tu empresa (solo las etapas activas) con cuántos documentos hay en cada una.
- Los indicadores cuentan expedientes abiertos, órdenes abiertas, monto ordenado, monto facturado, monto por pagar, facturas vencidas, aprobaciones y recepciones pendientes.
- "Ordenado contra facturado" compara los últimos 12 meses; pasa el cursor sobre la gráfica para ver las cifras.
- "Proveedores principales" ordena a tus proveedores por monto comprado.
- Las listas de atención muestran aprobaciones pendientes, facturas vencidas y órdenes que esperan recepción; haz clic en un documento para abrirlo.
- "Actividad reciente" lista los últimos documentos creados o modificados.
