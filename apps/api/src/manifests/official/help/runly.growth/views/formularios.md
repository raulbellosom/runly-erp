Consulta el desempeno de los formularios que estan generando leads para tu compania.

- Ve cuantas veces se envio cada formulario y que porcentaje de visitantes lo completo.
- Cada formulario esta ligado a un sitio conectado especifico; asi sabes de donde viene cada lead que capturas.
- Util para detectar que formulario esta funcionando mejor y replicar lo que le funciona a los que convierten menos.
