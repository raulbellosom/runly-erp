---
title: Growth
summary: Analitica de tu sitio, formularios y seguimiento de oportunidades de venta (leads).
---
Runly Growth convierte a los visitantes de tu sitio web en oportunidades de venta que puedes darles seguimiento.

- **Crecimiento**: analitica web (visitantes, sesiones, rebote, conversion) con adquisicion, contenido/CTA, conversiones y retencion D1/D7/D30.
- **Leads**: personas o empresas interesadas, capturadas desde formularios de tu sitio.
- **Sitios conectados**: que sitios web estan enviando datos a Growth.
- **Formularios**: los formularios que capturan leads, y cuales estan funcionando mejor.

### Alcances y limites

- Requiere el modulo de Contactos; los leads se convierten en contactos cuando avanzan en tu proceso de ventas.
- Necesita el modulo de Sitio web (u otro sitio conectado, incluida una pagina externa a Runly) para recibir datos reales de visitas y formularios.
- Los datos de analitica se pueden filtrar por periodo y por sitio, si tienes mas de uno conectado.
