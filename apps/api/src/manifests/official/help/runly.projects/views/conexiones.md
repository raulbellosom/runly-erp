title: Conexiones
summary: Activa y configura los modulos que agregan campos o registros a la ficha de cada proyecto.
---
Algunos modulos propios de tu empresa pueden **conectarse** a Proyectos para agregar informacion a cada proyecto; por ejemplo, un modulo de Presupuestos que agrega el monto autorizado.

- Cada modulo conectado aparece como una tarjeta con su tipo: **Campos** (datos extra del proyecto) o **Registros relacionados** (una lista, por ejemplo entregables o visitas de obra).
- Una conexion nueva llega **pendiente**: revisa sus campos y activala. Al activarla se toman en cuenta los registros que ya existian.
- Por cada campo decide donde se usa: **Formulario** (se edita al editar el proyecto y se guarda con el mismo boton), **Detalle**, **Columna** de la lista y **Busqueda**. Solo puedes elegir entre los campos que el modulo ofrece.
- Puedes desactivar una conexion en cualquier momento; los datos no se pierden y vuelven a mostrarse al activarla.
- Si un modulo conectado se desinstala, su conexion queda desactivada; si se reinstala, vuelve a activarse.
- Para ver esta pantalla necesitas el permiso **Gestionar conexiones de proyectos**. Si no aparece despues de una actualizacion, un administrador debe usar **Sincronizar modulos** una vez.
