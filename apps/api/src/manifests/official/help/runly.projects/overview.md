Runly Proyectos organiza el trabajo en proyectos con tareas, que puedes ver como tablero (arrastrando tarjetas entre columnas), como lista, o como linea de tiempo.

- Cada proyecto tiene sus propias columnas (por ejemplo, Backlog, En desarrollo, En revision, QA, Deploy) que puedes ajustar segun como trabaje tu equipo.
- Una tarea puede tener descripcion, prioridad, etiquetas, fecha de inicio/limite, responsable y subtareas.
- Cada tarea tiene su propio hilo de comentarios y espacio para adjuntar archivos y documentos, para no tener que buscar el contexto en otro lado.
- Un proyecto puede tener su propio canal de chat vinculado, para discutir el trabajo sin salir del contexto del proyecto.

### Alcances y limites

- Cambiar entre vistas (Kanban, Lista, Timeline) no cambia los datos, solo como los ves — la misma tarea se ve reflejada igual en cualquier vista.
- Las tareas tambien pueden aparecer en tu Calendario si tienen fecha, para verlas junto con el resto de tu agenda.
