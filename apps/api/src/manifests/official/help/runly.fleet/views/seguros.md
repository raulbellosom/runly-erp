title: Seguros
summary: Polizas de seguro de cada vehiculo.
---
Registra y consulta las polizas de seguro asociadas a cada vehiculo, incluida su vigencia.

- Cada poliza queda ligada a un vehiculo especifico, con su aseguradora, numero de poliza y fecha de vencimiento.
- Revisa esta pantalla periodicamente para renovar a tiempo las polizas proximas a vencer y evitar que un vehiculo quede sin cobertura.
