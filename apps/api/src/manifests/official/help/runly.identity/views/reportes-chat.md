viewKey: /identity/chat-reports
title: Reportes de chat
summary: Mensajes reportados por usuarios para revision de un administrador.
---
Cuando un usuario reporta un mensaje de chat como inapropiado, aparece aqui para que un administrador lo revise y decida que hacer.

- Cada reporte muestra el mensaje original, quien lo escribio, quien lo reporto y el motivo del reporte.
- Puedes descartar el reporte si no amerita accion, o tomar accion sobre el mensaje o el usuario involucrado segun corresponda.
- Los reportes ya resueltos quedan disponibles para consulta, con quien los atendio y que se decidio — util si el mismo usuario vuelve a ser reportado despues.
