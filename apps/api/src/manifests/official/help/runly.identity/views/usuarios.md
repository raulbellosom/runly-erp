title: Usuarios
summary: Crea, edita y desactiva las cuentas de usuario de esta instancia.
---
Aqui administras las cuentas que pueden acceder al sistema.

- Al crear un usuario le asignas un correo, un rol inicial y a que compania(s) pertenece.
- Puedes ver las sesiones activas de un usuario si tienes el permiso correspondiente.
- Desactivar (no eliminar) es la forma recomendada de dar de baja a alguien: conserva su historial de auditoria.
