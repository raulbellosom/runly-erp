---
Aqui se cobra: agregas productos a la cuenta, eliges la forma de pago y cierras la venta.

- Busca productos por nombre o categoria del Catalogo y agregalos a la cuenta; el total se calcula solo.
- Si el pedido viene del Comandero (mesa), la cuenta ya llega armada con lo que se pidio — solo confirmas y cobras.
- Elige la forma de pago (efectivo, tarjeta u otras que tengas configuradas) y, si aplica, divide el pago entre varias formas.
- Puedes vincular la venta a un contacto existente si quieres llevar su historial de compras.
- Al cerrar la venta se genera el ticket/recibo, listo para imprimir o enviar.
