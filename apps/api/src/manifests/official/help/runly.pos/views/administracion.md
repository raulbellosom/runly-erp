Ajustes generales del punto de venta: distribucion de mesas, impresoras de cocina/recibo y otras opciones operativas.

- El **plano de mesas** te deja dibujar la distribucion real de tu local (mesas, numeracion) para que el Comandero refleje donde esta sentado cada cliente.
- Configura que impresora recibe cada tipo de comanda (cocina, barra, recibo del cliente) segun como este organizada tu operacion.
- Estos ajustes son a nivel de punto de venta, no por cada venta individual — cambia aqui cuando reacomodes el local o agregues una impresora nueva, no en cada turno.
