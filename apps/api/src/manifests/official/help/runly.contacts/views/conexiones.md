title: Conexiones
summary: Activa y configura los modulos que agregan campos o registros a la ficha de cada contacto.
---
Algunos modulos propios de tu empresa pueden **conectarse** a Contactos para agregar informacion a cada contacto; por ejemplo, un modulo de Visitas que lista las visitas a cada cliente.

- Cada modulo conectado aparece como una tarjeta con su tipo: **Campos** (datos extra del contacto) o **Registros relacionados** (una lista, por ejemplo visitas o pedidos).
- Una conexion nueva llega **pendiente**: revisa sus campos y activala. Al activarla se toman en cuenta los registros que ya existian.
- Por cada campo decide donde se usa: **Formulario** (se edita al editar el contacto y se guarda con el mismo boton), **Detalle**, **Columna** de la lista y **Busqueda**. Solo puedes elegir entre los campos que el modulo ofrece.
- Puedes desactivar una conexion en cualquier momento; los datos no se pierden y vuelven a mostrarse al activarla.
- Si un modulo conectado se desinstala, su conexion queda desactivada; si se reinstala, vuelve a activarse.
- Para ver esta pantalla necesitas el permiso **Gestionar conexiones de contactos**. Si no aparece despues de una actualizacion, un administrador debe usar **Sincronizar modulos** una vez.
