Aqui administras el directorio completo de contactos.

- Filtra por tipo (cliente, proveedor, persona, empresa) y busca por nombre, correo, telefono o RFC.
- Cada contacto puede tener observaciones en texto enriquecido.
- Desde otros modulos veras un "selector de contacto" que reutiliza este mismo directorio.
