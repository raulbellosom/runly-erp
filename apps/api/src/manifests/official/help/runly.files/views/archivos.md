Aqui ves todos los archivos que tienes permiso de consultar, sin importar que modulo los subio originalmente.

- Puedes subir uno o varios archivos a la vez.
- La busqueda filtra por nombre.
- Puedes descargar varios archivos seleccionados de una vez (descarga masiva).
- Un link firmado te permite compartir un archivo privado por un tiempo limitado sin cambiar su visibilidad general.
