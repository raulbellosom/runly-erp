title: Documentos
summary: Plantillas de documento reutilizables y los PDF generados a partir de ellas.
---
Runly Documentos genera documentos PDF (contratos, cartas, constancias) a partir de plantillas reutilizables, llenando los datos automaticamente.

- **Plantillas**: el diseno y texto base del documento, con espacios (variables) que se llenan solos con datos reales al generar.
- **Generados**: el historial de documentos ya generados, listos para consultar o descargar de nuevo.

### Alcances y limites

- Cada version de una plantilla queda guardada; cambiar la plantilla no altera los documentos ya generados con la version anterior — quedan tal cual se generaron.
- Los documentos generados se guardan como archivos normales, disponibles tambien desde el modulo de Archivos.
